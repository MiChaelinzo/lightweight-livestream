Install the LightStream companion

This web app is a companion, not a mobile broadcaster. It installs the guide, preset calculator, and overlay page. It cannot capture a phone screen or publish RTMP video. LightStream does not ship an APK, AAB, or IPA.

Android: Chrome

  1. Open this page in Chrome.
  2. Open Chrome's menu and choose Install app or Add to Home screen.
  3. Confirm the name and tap Install.

If Chrome does not show the option, use the current HTTPS site rather than a copied local file, then reload once.

iPhone or iPad: Safari

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then tap Add.

Other iOS browsers may open Safari for this system install action.

What works after installation

  • The guide, preset calculator, install help, and demo companion shell remain available offline after one successful load.
  • Live Twitch data still needs a network connection. Tokens stay in the URL fragment and are not cached.
  • The desktop app's phone-remote link is separate. The desktop app creates that private local-network link only while a stream is running.

Why there is no mobile broadcaster package

The desktop product uses tkinter, desktop capture APIs, and a separate FFmpeg process. Android and iOS do not support that process model. A real mobile broadcaster needs native capture, encoding, background execution, permissions, and store signing. See the project roadmap for the separate Android and iOS architecture.

LightStream is MIT licensed. The installed companion stores no stream key.
